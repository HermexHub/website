## ✨ Ключові можливості

### 1. Фасетна фільтрація в сайдбарі (`SidebarFilters`)
- **Ізольований скрол:** Сайдбар прокручується незалежно від сторінки каталогу.
- **Staged Draft State:** Чекбокси обираються без передчасних запитів до мережі.
- **Динамічний лічильник:** Кнопка відображає кількість знайдених товарів: `Застосувати (9 знайдено)`.
- **Динамічні фасети:** Слайдер цін, бренди (Apple, Samsung, Asus, Dell, Sony...) та характеристики (процесор, RAM, SSD).

### 2. Сховище кошика (`useCartStore`) та авто-зцілення даних
- Архітектура Client-side First з `localStorage` персистентністю та захистом від hydration mismatch.
- **Батч-валідація (`POST /api/v1/cart/validate`):** Перевірка наявності та актуальності цін при відкритті кошика.
- Шкала безкоштовної експрес-доставки при сумі від 2 000 грн.

### 3. Оформлення замовлення та перехід до оплати
- Контактні дані та вибір способу доставки (Нова Пошта або кур'єр).
- Генерація унікального ключа `X-Idempotency-Key` (UUIDv4) для захисту від подвійних списань.
- Безшовний перехід до платіжного порталу на `/pay/:orderId`.

### 4. Live Order Tracker (Server-Sent Events)
- Потокові оновлення з `GET /api/v1/orders/:id/live` без поллінгу.
- Реактивна зміна статусу: `PENDING` ➔ `CONFIRMED` або `CANCELLED`.
- Автоматичний реконект з експоненційною затримкою.

### 5. Інтернаціоналізація (i18n)
- Підтримка української (`UA`) та англійської (`EN`) мов з миттєвим перемиканням у шапці.

## 🛠️ Запуск додатку

```bash
# Встановлення залежностей
bun install

# Запуск dev-сервера на порту 3000
bun dev

# Збірка продакшен-бандлу
bun run build

# Запуск продакшен-сервера
bun start
```
